About the plugin

Selling and buying in one place.

AutoTataru uses market data to help set selling prices and organizes the limits used during buying runs. Its in-game controls make each decision visible and let you stop a run.

  • Set minimum prices and undercut rules for items you sell.
  • Review buying limits before starting a shopping run.
  • See the decisions made during a run and stop it when needed.

Release status

AutoTataru is still being checked in game. Its download and installer entry will be added after the first public build is ready.
