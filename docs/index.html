One link for the collection

Install through Dalamud.

Add the repository once. Released plugins and their updates will appear in the plugin installer.

  1. 01

    Open Dalamud settings with /xlsettings in game.

  2. 02

    Under Experimental → Custom Plugin Repositories, add the URL below and save.

  3. 03

    Open /xlplugins and install the plugins you want.

https://ey4o.github.io/XIV-Plugins/repo.json
